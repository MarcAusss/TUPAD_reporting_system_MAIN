TUPAD ADL - Grants Automatically Mirrors Total
================================================

Business rule implemented:
- Grants = user input
- Administrative Cost = separate user input
- Total = automatically equal to Grants
- Administrative Cost is NOT added to Total

Example:
Grants:             8,000,000.00
Administrative Cost: 240,000.00
Total:              8,000,000.00

Security/data-integrity rule:
The controller ignores any submitted Total value and always stores Total = Grants.
This prevents a manipulated browser request from breaking the official rule.

Files in this overlay:
- app/Http/Controllers/AdlController.php
- resources/views/adl/_form-fields.blade.php
- resources/views/adl/create.blade.php
- resources/views/adl/edit.blade.php
- tests/Feature/AdlCoreInputTest.php

No migration is required.

Apply:
1. Extract this ZIP into the root of tupad-reporting-system.
2. Allow overwrite for the included files.
3. Run:

   php artisan optimize:clear
   npm run build
   php artisan test --filter=AdlCoreInputTest
   php artisan test

Expected UI:
Changing Grants immediately changes the readonly Total field.
Changing Administrative Cost does not change Total.
