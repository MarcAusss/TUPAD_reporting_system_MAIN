TUPAD REPORTING SYSTEM
PHASE 13 - SIDEBAR LAYOUT STABILITY FIX

ISSUE
-----
On desktop the main content still reserves the correct sidebar space, but
the actual sidebar children can collapse to a very narrow strip.

Visible symptoms:
- Navigation labels disappear.
- Sidebar scrollbar appears near the far-left edge.
- Signed-in card becomes extremely narrow and wraps every word.
- Header/logo may still look normal while the navigation body is broken.

FIX
---
The sidebar is now explicitly hardened as a fixed 252px desktop column.

Desktop rules:
- Sidebar width: exactly 252px.
- min-width/max-width: 252px.
- Sidebar children are forced to stretch to full width.
- Navigation scroll area cannot horizontally collapse/scroll.
- Navigation links consume full width.
- Icons do not shrink.
- Long labels use ellipsis instead of changing the sidebar width.
- Signed-in footer card remains full width.
- Main shell is explicitly offset by the same 252px.

Mobile:
- Sidebar remains off-canvas.
- Width is capped to the viewport so it still fits small screens.
- Existing open/close overlay behavior is preserved.

--------------
resources/views/layouts/app.blade.php
resources/css/app.css
