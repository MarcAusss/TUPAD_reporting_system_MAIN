TUPAD Reporting System
Major Revision Phase 13E - Hotfix 01
UserRole Import + Province Status Contract

PURPOSE
-------
This hotfix fixes the two compatibility failures remaining after Phase 13E:

1. VerifyReleaseReadiness.php referenced UserRole::TC without importing
   App\Enums\UserRole. PHP therefore attempted to resolve the enum as
   App\Console\Commands\UserRole and the release-verifier tests crashed.

2. DatabaseValidationHardeningTest still expected HTTP 404 when a TUPAD
   Coordinator submits a municipality belonging to another province.
   Phase 13D intentionally enforces cross-province access as HTTP 403.
   The production behavior is correct, so the stale test is updated to
   assert Forbidden instead of Not Found.

FILES REPLACED
--------------
app/Console/Commands/VerifyReleaseReadiness.php
tests/Feature/DatabaseValidationHardeningTest.php

DATABASE / DEPENDENCIES
-----------------------

No npm dependency.
No data rewrite.

APPLY
-----
1. Extract this ZIP over the Laravel project root.
2. Allow the two files above to replace the existing versions.
3. Run:
